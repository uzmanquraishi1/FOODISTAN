FOODISTAN – Your Cravings, Our Destination!

FOODISTAN is a modern and interactive food ordering simulator built using HTML, CSS, and JavaScript. It offers a seamless food ordering experience where users can explore food items, filter categories, manage their cart, place simulated orders, and track order history with cancellation and automatic delivery status updates.

Features:
Interactive food menu with category filtering
Add, remove, and manage cart items
Dynamic price calculation
Simulated order placement
Order cancellation within a 2-minute window
Automatic order status and delivery tracking
Order history management
Local Storage integration
Responsive and attractive UI

Technologies:
HTML5 | CSS3 | JavaScript (ES6+)
